# Нанаға арналған сайт ❤️ — соңғы нұсқа

Барлық қажетті өзгеріс бір `index.html` файлына енгізілген:

- Алғашқы бет: «Саған деген махаббатпен ❤️».
- Әуен: репозиторий түбіріндегі `music.mp3` (♫ батырмасы арқылы қосылады, циклмен ойналады, дыбыс 45%).
- Алты естелік атауы мен күні алдын ала толтырылған.
- Суреттер: `photos/01.jpg` — `photos/06.jpg`. Фото болмаса уақытша иллюстрация шығады.

## GitHub-қа жаңарту
1. Репозиторийдегі `index.html` файлын аш, қарындаш (Edit this file) арқылы осы жаңа файлдың мазмұнын толығымен қойып, **Commit changes** бас. Балама: ескі файлды өшіріп, жаңа `index.html` жүкте.
2. `photos` бумасын ашып, 6 жеке JPG суретті `01.jpg` ... `06.jpg` атауларымен жүкте. Түбірдегі басқа `preview_*.png` файлдары бұл алты естеліктің орнына автоматты шықпайды.
3. `music.mp3` түбірде қалсын. Егер басқа әуен қаласаң, дәл сол атпен жаңарт.
4. GitHub Pages Settings → Pages: main / (root) болуы керек.
5. Сілтеме: https://yernazar2004.github.io/mahabbat-alemi/

**Маңызды:** сайттағы параметрлерден фото ауыстыру тек өз браузеріңде сақталады. Нанаға көрсету үшін `photos` бумасына суреттерді GitHub арқылы жүкте немесе «📤 GitHub-қа арналған файлды алу» арқылы жарияланатын HTML экспорттап қайта жүкте. Фото мен жазулар жалпыға ашық GitHub репозиторийінде көпшілікке көрінеді.
