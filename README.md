# Біздің махаббат әлеміміз ❤️

Бұл видеодағы сайт стилінде жасалған, телефон мен компьютерге бейімделген интерактивті 3D галереяның бастапқы нұсқасы.

## Іске қосу

1. `index.html` файлын браузерде ашыңыз. Қосымша кітапхана не интернет қажет емес.
2. Немесе VS Code → Live Server кеңейтімі арқылы `index.html` файлын ашыңыз.
3. «Ашу ❤️» батырмасын басыңыз.

## Басқару

- Телефон: сол жақ төмендегі джойстикпен жылжыңыз, сахнада оңға/солға сырғытып бұрылыңыз.
- Компьютер: W/A/S/D — жүру; сол/оң бағыттауыштар — бұрылу; тышқанмен сүйреп те бұрылуға болады.
- «Келесі бөлме» батырмасымен үш бөлмені аралаңыз.
- Қабырғадағы фотоны немесе хатты басып ашыңыз.

## Өзгерту

Жоғарғы оң жақтағы ☰ батырмасын басып, арнау есімін, автор есімін, хатты, сурет атауларын өзгертіңіз. «Фото жүктеу» арқылы 6 фото қоса аласыз. Фотолар осы браузердің localStorage қоймасында сақталады; басқа құрылғыға автоматты түрде өтпейді.

«♫» батырмасы авторлық синтезделген әуенді қосады. «Өз музыкамды таңдау» арқылы компьютер/телефондағы аудиофайлды қосуға болады (файл бет жабылған соң сақталмайды).

Барлық HTML, CSS және JavaScript бір `index.html` ішінде. CDN, Three.js, сервер не тіркелгі қажет емес. 3D кеңістік CSS перспективасы негізінде жасалған.
